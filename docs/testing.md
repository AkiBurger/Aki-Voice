# 测试说明

项目里有两个可以自动跑的检查脚本，都在 `tools/` 和 `src/backend/` 下。

## 环境准备

- 后端已启动：<http://127.0.0.1:8017/api/health> 返回 `status: ok`
- 自检里的合成 / 评测项需要声音引擎（9880）已启动
- 界面冒烟需要 Node.js 18+（用了内置 WebSocket）和 Microsoft Edge
- `tools/ui_smoke.js` 顶部写死了 Edge 路径，Edge 装在别处时改那一行

## 后端自检

```bat
<GPT-SoVITS 的 venv>\Scripts\python.exe src\backend\selftest.py
```

覆盖内容：

- 后端健康、引擎 /docs
- 模型列表、模型下拉、参考音频试听
- 日文合成、中文→日文翻译合成
- 合成历史、测试句、评测历史
- 训练数据与训练状态
- 前端页面元素、静态文件缓存头
- 引擎可用性

结果输出到 `data/_selftest.txt`，正常是「通过 15 项，失败 0 项」。
失败时会打印 `[FAIL]` 和原因，按提示查对应的服务或接口。

注意：自检会真的调用合成和评测，会往 `outputs/` 和评测历史里写记录。

## 界面冒烟测试

```bat
node tools\ui_smoke.js
```

启动无头 Edge，依次打开合成、素材、质检、标注、训练、评测页面，检查：

- 页面标题、导航数量
- 素材数量、搜索、训练数据状态、评测历史
- 有没有 JS 异常或 console error

正常输出里 `errors` 和 `consoleErrors` 都是空数组。
数据为空时，素材数量为 0 属于正常。

## 波形 / A-B 回归脚本（可选）

```bat
node tools\ui_wave_ab_test.js
```

旧版回归脚本，依赖页面上的一些元素和稳定的数据。页面结构改动后可能失效，不需要每次跑。
截图输出到 `docs/assets/_waveform-test.png`（不会覆盖 README 用的截图）。

## 手动检查清单

发布或大改后建议手动过一遍：

- 启动器能启动引擎、后端并打开页面
- 合成：空文本时按钮禁用；正常文本能出音频；结果面板可播放、下载
- 切换模型后，顶部徽章、说话人名牌、合成结果一致
- 素材：导入、识别、删除、恢复删除
- 质检：跑一次，筛选，删除不合格
- 标注：修改文本保存后有提示，刷新后仍在
- 训练：数据不齐时不能开始；参数越界有中文提示
- 评测：进度显示第 N/11 句，结束后出分数
- 设置：动效开关、音色名称、模型管理、清理空间（清理后设置面板不关闭）
- 浏览器控制台没有报错

## 持续集成

仓库目前没有配置 CI。如果要在 GitHub Actions 里跑，建议先做静态检查：

- `python -m py_compile` 后端全部文件
- `node --check src/static/app.js`
- 需要服务的 selftest 和 ui_smoke 不适合直接在 CI 里跑，除非用 mock 或跳过需要 GPU 的项
