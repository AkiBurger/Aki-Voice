# AkiBurger Voice · 视觉规范 v3「アニメ・ゲーム HOME」

> v0.3.0 界面权威文件。取代 v0.2 的 `MASTER.md`。
> 定稿方向（用户确认）：**A 游戏主界面式骨架 + C 的 galgame 氛围**。
> 参考气质：ufotable 光影 / 新海诚电影感 / galgame CG。只借风格语言，全部素材为本地 AI 生成的原创图，无版权角色。

## 0. 一句话

全屏动漫场景 + 右侧原创少女立绘 + 左侧编号大菜单 + 底部 galgame 大对话框（同时是真实可用的输入 HUD）+ 亮色蓝粉玻璃；唯一动效是页面切换。

## 1. 素材（`src/static/assets/`）

| 文件 | 用途 | 说明 |
|---|---|---|
| `hero-idle.webp` | 默认/所有页面背景 | 樱花天空+右侧少女（1920×1275） |
| `hero-happy.webp` | 合成/评测/训练成功 | 同构图、表情开心 |
| `hero-thinking.webp` | 合成中/评测中/导入中 | 同构图、思考表情 |
| `hero-sad.webp` | 失败/错误 | 同构图、难过表情 |
| `hero-surprised.webp` | 切换模型/参考（可选） | 同构图、惊讶表情 |

- 立绘放置：右侧，宽约 460~520px，底部/左侧渐隐（mask 或渐变遮罩），不遮挡按钮；<1100px 缩小，<860px 隐藏。
- 背景：`object-fit: cover`，加蓝粉渐变 + 白色半透明蒙版保证文字可读。
- 字体：`src/static/fonts/zcool-qingke-huangyou.woff2`（OFL；中文/拉丁展示字体，**无日文假名**）。日文台词用系统字体（Yu Gothic/Meiryo 回退），正文系统无衬线。

## 4. 动效（唯一动态：页面切换）

| 场景 | 动效 | 时长 |
|---|---|---|
| 页面切换 | 斜切面板扫过（clip-path polygon 位移）+ 新内容 8px 上滑淡入 | ≤320ms |
| hover | 亮度/边框变化；CTA 流光 | 140ms |
| press | scale(.98) | 100ms |
| 结果出现 | 下方 12px 滑入 | 260ms |
| 进度条 | 斜纹流动 | 常驻（1 个元素） |
| 立绘状态切换 | 静态图片切换 + 120ms 淡入 | 120ms |
| reduced-motion | 全部退化为无位移淡入 | — |

**禁止**：canvas/rAF 粒子、持续背景动画、全屏扫光、backdrop-filter、动画 blur/box-shadow。

## 6. 可访问性与性能

- 正文 ≥4.5:1；大标题 ≥3:1；CTA 白字在渐变上 ≥4.5:1（必要时加深渐变）。
- 焦点可见（2px ring）；`aria-current` 保留；图标按钮 aria-label。
- 静态 60fps；转场 ≥55fps；页面隐藏暂停一切动画。
- 素材 WebP，总体积控制在 5MB 内。
