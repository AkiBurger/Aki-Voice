## 三、GitHub 建仓步骤

> 当前本地仓库还没配置远程（`git remote -v` 为空），按下面步骤加。

### 3.1 先在本地提交

发布由维护者统一提交，其他协作者不要碰 git。

```powershell
cd D:\Dev\projects\voice-studio

# 1) 确认工作区
git status --short

# 2) exe 移出版本库（保留本地文件）
git rm --cached AkiBurgerVoice.exe
# 并在 .gitignore 里加一行：/AkiBurgerVoice.exe

# 3) 放行训练脚本（关键！）
#    如果 .gitignore 还是整体忽略 data/，clone 下来会缺 train.py / batch_asr.py / clean_data.py。
#    确认 .gitignore 里改成下面几条（父目录也要放行）：
#      data/*
#      !data/setsuna/
#      data/setsuna/*
#      !data/setsuna/*.py
#    然后验证：git check-ignore -v data/setsuna/train.py   → 应该不再命中

# 4) 提交
git add -A
git commit -m "开源发布 v0.2.0"
```

> `.gitignore` 注意：父目录被忽略时，子文件的 `!` 反忽略不生效。
> 所以必须先把 `data/` 换成 `data/*`，再放行目录和 `*.py`，音频 / `.list` 继续被忽略。

### 3.2 在 GitHub 建公开仓库

1. 打开 <https://github.com/new>
2. Owner 选 `AkiBurger`，Repository name 填 `voice-studio`
3. 可见性选 **Public**
4. **不要**勾选 "Add a README file" / "Add .gitignore" / "Choose a license"（本地已有）
5. Create repository

用 `gh` CLI 也行：

```powershell
gh repo create AkiBurger/voice-studio --public --source=. --remote=origin
```

### 3.3 关联远程并推送

```powershell
git branch -M main
git remote add origin https://github.com/AkiBurger/voice-studio.git   # 或 git@github.com:AkiBurger/voice-studio.git
git push -u origin main
```

推送后检查：

- [ ] 仓库首页 README 正常渲染，License 显示 MIT
- [ ] `docs/` 能点开、中文不乱码
- [ ] 仓库体积正常（几十 MB 以内，没有混进权重 / 音频）
- [ ] 仓库是 Public

### 3.4 打 tag、发 Release

```powershell
git tag -a v0.2.0 -m "AkiBurger Voice v0.2.0"
git push origin v0.2.0
```

GitHub → Releases → **Draft a new release**：

| 字段 | 填什么 |
|---|---|
| Choose a tag | `v0.2.0`（刚推的 tag） |
| Release title | `AkiBurger Voice v0.2.0` |
| Describe this release | 用下面第四节的模板 |
| 附件 | `AkiBurgerVoice.exe`、`SHA256SUMS.txt`（可选：截图、演示音频） |

**不要打包进 Release：** 模型权重、GPT-SoVITS 本体、训练音频、`outputs/`、`logs/`。

### 4.2 Release Notes 模板

```markdown
## AkiBurger Voice v0.2.0

本地 Windows 声音克隆流水线：素材 → 质检 → 标注 → 训练 → 评测 → 合成。
界面全中文，数据不出本机。

### 包含
- 六页完整流程（素材 / 质检 / 标注 / 训练 / 评测 / 合成）
- 一键训练 GPT-SoVITS v2Pro 模型，训完自动挂载、可自动评测
- 声纹相似度评测（ERes2NetV2），把"像不像"变成分数
- 中 / 日 / 英合成 + 跨语言翻译（Ollama Qwen 优先，内置中→日模型兜底）
- C# 启动器：双击拉起引擎 / 后端并打开界面

### 不包含（需要自己准备）
- GPT-SoVITS 本体与 v2Pro 预训练模型（按 GPT-SoVITS 官方 README 下载）
- 任何训练好的音色权重
- 任何音频素材

### 环境要求
- Windows 10/11 64 位
- Python 3.10+（推荐直接复用 GPT-SoVITS 的 venv）
- NVIDIA 显卡，8GB 显存起步
- ffmpeg

### 已知限制（v0.2）
- 启动器与部分模块的路径按作者机器目录布局写死；换目录需改 `launcher/launcher.cs` 等常量后重编译
- `config.example.json` 中 `paths.*` / `backend.*` / `tts.*` 为预留配置项，当前版本未接入
- 语气判断为关键词规则 v1；语气参考库需先运行 `python data/setsuna/build_tones.py` 生成，未生成时所有语气退回默认参考音频
- 仅 Windows

### 安装
见仓库 README 的「快速开始」。exe 放到项目根目录双击即可（目录布局需一致）。

### 许可
MIT。仅供合法用途：只克隆你有权使用的声音，禁止冒充他人与违法用途。
详见 README 的「免责声明」。
```

## 五、已知限制（发布时必须如实写）

| # | 限制 | 影响 | 后续 |
|---|---|---|---|
| L1 | `launcher/launcher.cs` 写死 `D:\Dev\projects\voice-studio`、`D:\Dev\ai`、`D:\Dev\tools\ffmpeg\bin` | 换目录的 exe 不可用 | 后续改为读 `config.json` / 相对路径 |
| L2 | `app.py` / `trainer.py` / `evaluate.py` 在 `D:\Dev\ai\02_GPT-SoVITS_*` 下探测引擎；`data_prep.py`、`translate_local.py`、`data/setsuna/train.py`、`batch_asr.py`、`clean_data.py` 也写死了路径（其中 `batch_asr.py` 连 Fun-ASR 模型的快照目录都写死了） | 目录不合约定时需改源码，或设置 `ABV_SOVITS_ROOT` / `ABV_ENGINE_URL` 等环境变量 | 配置化 |
| L3 | `config.example.json` 中 `paths.*`、`backend.*`、`tts.*`、`output_dir`、`data_dir` 为预留项，代码暂未读取 | 改配置不改变运行行为 | 接 `load_config()` |
| L4 | 语气判断为关键词规则 v1；语气参考库需手动生成（`data/setsuna/build_tones.py`），未生成时退回默认参考音频 | 不生成语气库时，不同语气的差异不明显 | 语气判断后续升级为本地大模型 |
| L5 | 跨语言（中 / 英）相似度低于本人语言 | 属模型能力，不是 bug | 数据与参考音频优化 |
| L6 | 仓库不含模型与权重 | 首次部署要自己下几个 GB | 保持（协议 + 体积原因） |
| L7 | 仅 Windows（文件夹选择框 PowerShell、`taskkill` 杀进程树、WinForms 启动器） | 其它平台无法直接用 | 不计划 |
