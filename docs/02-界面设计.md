# 一、设计定稿与权威文件

- **用户确认的方向**：**A 游戏主界面式骨架 + C 的 galgame 氛围**。
- **气质参考**：ufotable 光影 / 新海诚电影感 / galgame CG。**只借风格语言**；全部素材为本地 AI 生成的原创插画，无版权角色。
- **权威规范**：[`design-system/akiburger-voice/MASTER-v3.md`](../design-system/akiburger-voice/MASTER-v3.md)。
  颜色、字体、组件、图标、动效、无障碍以它为准；本文档记录实现落点。
- **一句话**：全屏动漫场景 + 右侧原创少女 + 左侧编号大菜单 + 底部 galgame 对话框（同时是真实可用的输入 HUD）+ 亮色蓝粉玻璃；唯一动效是页面切换。

# 二、素材与字体（全部离线）

## 2.1 主视觉（`src/static/assets/`）

| 文件 | 使用的表情 | 说明 |
|---|---|---|
| `hero-idle.webp` | 默认 / 空闲 | 樱花天空 + 右侧少女（1920×1277；其余 4 张同构图 1920×1275，只换表情），同时是所有页面的默认背景 |
| `hero-happy.webp` | 成功（合成 / 评测 / 训练完成） | 同构图、开心表情 |
| `hero-thinking.webp` | 等待（合成中 / 评测中 / 导入中 / 训练中） | 同构图、思考表情 |
| `hero-sad.webp` | 失败 / 错误 | 同构图、难过表情 |
| `hero-surprised.webp` | 切换模型 / 参考音频 / 点语气 | 同构图、惊讶表情 |

- 角色直接画在**全屏背景**里（不再是独立立绘层），放在画面右侧；左侧文字与面板压在提亮蒙版上保证可读。
- 5 张 WebP 合计约 **1.15 MB**；`hero-idle` 用 `<link rel="preload">` 预加载，其余在启动后预加载。
- 表情切换 = 双图层（`#sceneA` / `#sceneB`）**120ms 交叉淡入**，只动 opacity。
- 右上齿轮的设置里可以**关闭主视觉背景**（`body.no-char` → 回退纯色蓝粉渐变，功能不受影响）。

## 2.2 字体

| 用途 | 字体 | 来源 / 许可 |
|---|---|---|
| 展示字体（品牌、菜单编号、页面标题、卡片标题、LAST TAKE / BACKLOG / 声の設定 标签） | **站酷庆科黄油体**（ZCOOL QingKe HuangYou） | 本地 `src/static/fonts/zcool-qingke-huangyou.woff2`，**OFL 开源**，许可证见同目录 `OFL-ZCOOL.txt` |
| 正文 UI（按钮、说明、表单） | 系统无衬线：`Segoe UI / Microsoft YaHei / Yu Gothic UI` | 系统自带，无外部字体请求 |
| 台词与标题氛围 | 明朝体回退：`Yu Mincho / Hiragino Mincho ProN / Noto Serif SC / SimSun` | 系统自带 |
| 日志 / 分数 / 时间 | 等宽：`Cascadia Mono / Consolas` | 系统自带 |

> ⚠️ 站酷庆科黄油体**不含日文假名**：日文台词与角色名（雪菜 / CV / 日语文本）自动回退到系统日文字体（`--font-jp`）。

## 2.3 图标

- 禁止 emoji 当图标；全部使用 `index.html` 顶部的隐藏 SVG sprite（32 个 Lucide 风格 `<symbol>`，线性描边、`currentColor`）。
- 用法：`<svg class="icon" aria-hidden="true"><use href="#i-play"/></svg>`；纯装饰图标 `aria-hidden="true"`，图标按钮必须带 `title` + `aria-label`。

## 2.4 离线声明

界面**不请求任何外部 CDN / 字体 / 图片**：主视觉、字体、图标全部随仓库提供，断网也能正常显示。

# 六、角色状态机（5 种表情）

**注意：角色只有 5 种表情；语气（TTS 参数）仍然是 6 种 + 自动。两者不是一一对应关系。**
表情是"界面氛围反馈"，语气是"合成时的参考音频选择"。

| 触发场景 | 表情 |
|---|---|
| 默认 / 空闲 / 切到其它页面 | `idle`（默认） |
| 合成开始、评测开始、素材导入、识别 + 清洗轮询、训练运行中 | `thinking` |
| 合成成功、评测完成、训练完成、导入/清洗完成 | `happy` |
| 任何失败：合成 / 评测 / 训练 / 导入 / 接口报错 | `sad` |
| 切换模型、切换参考音频、点语气按钮 | `surprised` |

**实现细节（`src/static/app.js`）**

- 5 张图对应 5 个状态；切换时双图层 `sceneA` / `sceneB` 交叉淡入（120ms，只动 opacity）。
- 临时表情自动回落：`happy` / `sad` 约 2.6 秒后回到 `idle`（若合成进行中回 `thinking`）；`surprised` 约 1.4 秒后回落。
- 设置里关闭"显示主视觉背景"后不再切换表情（`body.no-char` 隐藏场景层），功能不受影响。

# 七、动效规范（唯一动态 = 页面切换）

| 场景 | 动效 | 时长 |
|---|---|---|
| **页面切换（唯一主动态）** | P5 风格双斜切面板扫过（深蓝主面板 + 樱粉窄条，`skewX(-9deg)` 位移） | 240ms，第二层延迟 22ms |
| 页面内容出现 | 新内容 `translateY(8px → 0)` 淡入 | 240ms |
| 结果面板首次出现 | 从下方 16px 滑入 | 280ms |
| 角色表情切换 | 背景图交叉淡入 | 120ms |
| 悬停 / 按下 | 亮度、边框、背景变化；菜单项 4px 位移；CTA 上浮 1px / 按下回落 | 140~160ms |
| 进度条 | 宽度 transition；无真实百分比时显示静态斜纹（不做持续动画） | 350ms |

**禁止**：canvas / rAF 粒子、持续背景动画、全屏扫光、`backdrop-filter`、动画 blur / box-shadow。

**可关闭**：右上齿轮 →「页面切换动效」开关（存 `localStorage` 的 `abv:motion`）；
系统 `prefers-reduced-motion: reduce` 时自动关闭斜切与一切动画。

**合成页专属浮层**：只有 `body[data-view="synth"]` 时显示对话框、LAST TAKE、声の設定、BACKLOG、批量面板、错误/引擎提示；其它 5 页隐藏，主内容区占据画面。

## 9.1 合成页交互流程

1. **台词**：大号明朝体输入框，实时显示字数与预计时长（估算），可清空。
2. **语言**：输入语言（中 / 日 / 英）→ 输出语言（中 / 英 / 日）；不同语言自动翻译，下方一句话说明当前行为。
3. **语气**：自动判断（显示"自动判断为「X」+ 置信度"），也可在 6 种语气 + 自动之间手动点选；语气会按参考音频库切换实际参考音频。
4. **合成**：主 CTA「合成」（Ctrl+Enter）；合成中 CTA 上方出现进度（静态斜纹 + 状态文字），角色切 `thinking`；成功切 `happy` 并弹出 LAST TAKE；失败切 `sad` 并弹出错误面板。
5. **结果（LAST TAKE）**：翻译核对（跨语言时）→ 播放器 → 元信息 → 波形 → A/B 对比；操作：下载 / 设为参考 / 存成预设。
6. **历史（BACKLOG）**：左下方胶囊显示条数，展开后是历史列表（播放 / 下载 / 设为参考 / 删除）与「清空历史」。
7. **声の設定**：当前音色（下拉 / 试听 / 改名）、参考音频（自动按语气挑选 / 固定某条）、音质微调（稳定度 / 随机种子，折叠）、预设（套用 / 删除）。

## 9.2 其它页

- 使用同一外壳（背景 / 左菜单 / 顶栏 / 角色），主面板换成玻璃卡片；页面右侧留出主视觉人物的空间。
- 所有原有功能（导入 / 质检 / 标注 / 训练 / 评测）不变，操作路径是"左侧 01~06 切页 → 页面内卡片"。

# 十、交互与快捷键

| 分类 | 快捷键 / 操作 | 说明 |
|---|---|---|
| 合成 | `Ctrl+Enter` | 立即合成（仅合成页；进行中防重复） |
| 结果 | `空格` | 播放 / 暂停结果音频（焦点不在输入框、LAST TAKE 可见时） |
| 设置 | `Esc` | 关闭设置浮层 |
| 设置 | 点击浮层外 | 关闭设置浮层 |
| 导航 | 点击左侧 01~06 | 切页；同步 hash（`#synth` 等），支持浏览器前进 / 后退 |
| 焦点 | `Tab` / `Shift+Tab` | 按视觉顺序移动，`:focus-visible` 可见 |

- 设置项记忆在浏览器本地：`abv:motion`（页面切换动效）、`abv:char`（主视觉背景）。
- 页面切换时数据加载延后约 300ms（素材页 820ms），避免长列表渲染卡住转场动画。
- 错误用人话：标题说问题、说明写下一步；引擎未就绪会区分"后端不可达 / 引擎加载中 / 健康检查失败"。

# 十一、无障碍

- 页面首个可聚焦元素是「跳到主内容」链接（`#main`）；内容区 `<main id="main" tabindex="-1">`。
- 全局 `:focus-visible`：2px 主色外框 + 2px offset。
- 左侧菜单 `<nav aria-label="主导航">`；当前项 `aria-current="page"`；折叠/展开按钮带 `aria-expanded` / `aria-controls`。
- 图标按钮 `aria-label`；纯装饰图标 `aria-hidden="true"`。
- 语义色同时配文字（不单靠颜色）；正文对比按 MASTER-v3 要求（≥4.5:1）。
- 支持 `prefers-reduced-motion`：关闭斜切转场与一切动画。

# 十二、响应式

| 断点 | 行为 |
|---|---|
| ≥1320px | 基准：左菜单 240px；对话框 left 258 / right 28；声の設定 302px；内容区右侧留 420px |
| ≤1320px | 声の設定 282px；对话框 left 238；浮层 520px；内容右留白 370px |
| ≤1150px | 左菜单 204px；品牌与菜单字号缩小；对话框 left 214；声の設定 266px；内容右留白 320px |
| ≤1000px | 左菜单收成 **76px 图标版**（隐藏品牌文字 / 编号 / 英文小字 / 底部状态）；顶栏 left 76；版本徽标隐藏；声の設定 258px |
| ≤860px | 左菜单 64px；顶栏 66px（隐藏 kicker）；对话框 left 72 / right 8；浮层自动宽度；BACKLOG 隐藏；对话框字号 19px；次要徽标隐藏 |
| ≤640px | 声の設定 隐藏；浮层抬高到底部对话框上方 |

目标：**不出现横向滚动条**，主视觉人物不遮挡按钮。

# 十三、性能

| 指标 | 实测 / 约束 |
|---|---|
| 静止帧率 | 1440×900 下 60fps（headless Edge `--disable-gpu`） |
| 转场帧率 | 约 59.9fps |
