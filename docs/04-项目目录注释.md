# 项目目录注释

说明每个目录和文件的用途，以及哪些是运行数据、哪些会提交到仓库。

## 顶层

```
voice-studio/
├─ src/                 源代码（后端 + 前端）
├─ data/                本机数据：训练脚本、素材、参考音频、模型注册表
├─ outputs/             合成产物（运行后生成，不进仓库）
├─ logs/                运行日志（运行后生成，不进仓库）
├─ docs/                文档和截图
├─ launcher/            启动器源码
├─ tools/               自检和回归脚本
├─ .github/             Issue / PR 模板
├─ AkiBurgerVoice.exe   启动器（编译产物，不进仓库）
├─ 启动.bat             双击启动入口
├─ 清理痕迹.bat         发布前清理本机痕迹
├─ config.json          本机配置（不进仓库）
├─ config.example.json  配置示例（进仓库）
├─ requirements.txt     Python 依赖
├─ README.md
├─ LICENSE
├─ CONTRIBUTING.md
└─ THIRD_PARTY_NOTICES.md
```

## src/backend

FastAPI 后端，监听 127.0.0.1:8017。

| 文件 | 作用 |
|---|---|
| `app.py` | 所有 HTTP 接口、静态托管、模型注册与启用、维护清理 |
| `engine.py` | 调用 GPT-SoVITS 引擎（9880）：健康检查、切换权重、合成 |
| `data_prep.py` | 素材导入、删除、恢复、扫描、转码 |
| `trainer.py` | 训练任务编排、进度解析、训练后挂载权重 |
| `evaluate.py` | 声纹评测：固定测试句、打分、写历史 |
| `qc.py` | 质检：音频指标和文本检查 |
| `annotate.py` | 标注读写 |
| `emotion.py` | 从文本判断语气 |
| `text_split.py` | 长文本切句 |
| `translate.py` / `translate_local.py` | 翻译调度与内置中→日模型 |
| `folder_picker.py` | Windows 文件夹选择框 |
| `project_paths.py` | 项目、数据、GPT-SoVITS、ffmpeg、HF 缓存的路径解析 |
| `selftest.py` | 15 项后端自检 |
| `requirements-note.txt` | 环境说明备注 |

## src/static

纯静态前端，没有构建步骤。

| 文件/目录 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `styles.css` | 样式、布局、动效、响应式 |
| `app.js` | 交互逻辑 |
| `assets/` | 背景图 5 张 + 干净底图 1 张 |
| `fonts/` | 展示字体和 OFL 许可 |

## data

本机数据目录。仓库只跟踪 `data/voice/` 下的 4 个 Python 脚本，其余都不跟踪。

| 路径 | 内容 | 提交 |
|---|---|---|
| `data/voice/train.py` | 训练脚本 | 是 |
| `data/voice/batch_asr.py` | 批量识别脚本 | 是 |
| `data/voice/clean_data.py` | 清洗脚本 | 是 |
| `data/voice/build_tones.py` | 语气参考库生成脚本 | 是 |
| `data/voice/wav/` | 导入的音频 | 否 |
| `data/voice/voice.list`、`voice_clean.list` | 标注清单 | 否 |
| `data/voice/list_backups/` | 清单备份 | 否 |
| `data/ref/` | 参考音频、语气库 | 否 |
| `data/theme/` | 自定义背景和立绘 | 否 |
| `data/models.json` | 模型注册表和当前启用项 | 否 |
| `data/voice.json` | 音色显示名 | 否 |
| `data/evaluations.json` | 评测历史 | 否 |
| `data/qc_report.json` | 最近一次质检报告 | 否 |
| `data/_trash/` | 删除素材的回收站 | 否 |
| `data/_model_trash/` | 删除模型的权重备份 | 否 |

旧版本的数据目录名不同时，代码会自动识别并继续使用，不需要手动改名。

## outputs / logs

| 目录 | 内容 | 清理 |
|---|---|---|
| `outputs/<时间戳>/` | 每次合成的音频、波形、元信息 | 设置 → 清理空间 → 合成产物 |
| `outputs/_eval/` | 评测产物 | 保留 |
| `logs/*.log`、`*.out`、`*.err` | 启动器、引擎、后端、训练日志 | 设置 → 清理空间 → 日志 |

## launcher

| 文件/目录 | 作用 |
|---|---|

| `build.bat` | 用 csc 编译，内嵌 manifest、背景、图标、字体子集 |
| `assets/app.manifest` | 高 DPI 声明 |
| `assets/bg-*.jpg` | 启动器背景 |
| `assets/app.ico`、`app-icon.png` | 图标 |
| `assets/ZCOOLQingKeHuangYou-subset.ttf.gz` | 字体子集 |
| `assets/make-font-subset.py` | 重新生成字体子集 |

## tools

| 文件 | 作用 |
|---|---|
| `ui_smoke.js` | 无头浏览器检查页面和 console error |
| `ui_wave_ab_test.js` | 波形 / A-B 回归脚本（可选） |

## 提交与忽略

会提交：`src/`、`data/voice/*.py`、`docs/`、`launcher/`、`tools/`、`.github/`、README、LICENSE、CONTRIBUTING、THIRD_PARTY_NOTICES、requirements、config.example.json、启动.bat、清理痕迹.bat。

不提交：`data/` 下除脚本外的内容、`outputs/`、`logs/`、模型权重、`AkiBurgerVoice.exe`、`__pycache__`、`.venv`、`config.json`。
