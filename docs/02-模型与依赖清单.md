# 模型与依赖清单

仓库只放代码、文档、界面图片和字体。模型、训练数据、声音素材都靠本地准备。

## 必需

| 组件 | 用途 | 获取方式 | 体积 |
|---|---|---|---|
| GPT-SoVITS v2Pro | 声音合成和训练引擎 | [官方仓库](https://github.com/RVC-Boss/GPT-SoVITS)，按它的文档下载 v2Pro 预训练模型 | 代码 + 预训练模型约 10GB 以上 |
| Python | 后端和脚本运行 | GPT-SoVITS 自带的 venv 即可 | — |
| ffmpeg | 素材转码、音频读取 | 自行下载 Windows 版 | 约 100MB |
| NVIDIA 显卡 | 训练和合成 | 8GB 显存起步 | — |

Python 包见 `requirements.txt`。已经有 GPT-SoVITS venv 时不要重复安装 torch / transformers，避免覆盖 CUDA 版本。

## 可选

| 组件 | 用途 | 说明 |
|---|---|---|
| FunASR + Fun-ASR-Nano | 素材页的「识别 + 清洗」 | 模型约 1.9GB，放 HuggingFace 缓存；需要设置 `ABV_FUNASR_SNAPSHOT` |
| Ollama + Qwen3 | 更自然的翻译 | 不装时使用内置 opus-mt 小模型（仅中→日） |
| opus-mt-zh-ja | 内置中→日翻译 | 约 300MB，首次使用时从 HuggingFace 缓存加载 |
| ERes2NetV2 | 评测的声纹打分 | 随 GPT-SoVITS 的预训练模型一起提供 |
| .NET Framework 4.x | 重新编译启动器 | Windows 自带 csc.exe，不需要 Visual Studio |
| fontTools | 重新生成启动器字体子集 | 只在改展示字体时需要 |

## 磁盘预算

| 内容 | 大约 |
|---|---|
| GPT-SoVITS 代码 + v2Pro 预训练模型 | 10GB 以上 |
| Fun-ASR-Nano | 1.9GB |
| opus-mt-zh-ja | 300MB |
| 本项目仓库 | 约 15MB |
| 每轮训练权重 | SoVITS 约 129MB，GPT 约 148MB |
| 训练特征与日志 | 视素材量，几百 MB 到几 GB |
| 合成产物 | 每段几百 KB，可在设置里清理 |

- GPT-SoVITS、FunASR、3D-Speaker、opus-mt、Qwen3：各自许可

## 不随仓库分发

- 声音素材、参考音频、训练数据、标注文件
- SoVITS / GPT 权重
- 预训练模型、ASR 模型、翻译模型
- 启动器 exe

`.gitignore` 已经排除这些内容。换机器时请自行备份 `data/` 和 GPT-SoVITS 的权重目录。

## 路径配置

程序默认按项目位置推断：

- GPT-SoVITS：项目上两级的 `ai/` 下查找
- ffmpeg：`ai/../tools/ffmpeg/bin`
- HuggingFace 缓存：`ai/../cache/huggingface/hub`

不符合时用环境变量覆盖，完整列表见 [install.md](install.md#五路径与环境变量)。
