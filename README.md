## 这是什么

一套完整的项目设计文档。描述了一个**桌面软件**：

> **一个集成开发软件，力争本地就能自己训练模型并且克隆出最像的声音，且可以自己调整优化的人声输出。**

它做两件事：

1. **造声音** —— 导入音频，自动清洗、自动识别、自动训练、自动评测，产出人声模型
2. **用声音** —— 选一个训练好的人声模型，输入文案，输出中文／英文／日文配音

**它解决的核心问题**：不是"能不能克隆声音"（这已经能了），而是
**"怎么让声音更像"** 和 **"怎么让人真正学会调"**。

## 三句话抓住重点

**1. 一条线走完**
素材 → 质检 → 标注 → 训练 → 评测 → 合成。顶部一条导航，随时知道自己在第几步。

**2. 每一环都用过心的**
不是"抓一个模型包一层界面"。识别用 FunASR（日语错误率 25%，Whisper 是 39%）、
切分用 FSMN-VAD、质检用声纹比对查混入的他人声音、纠错用本地大模型。
**每一项都有实测数据支撑。**

**3. 把"像不像"变成数字**
训完自动用声纹模型打分，按分数分类，帮你快速筛掉不行的版本、留下好的几版让人选。
**没有这一步，训练就是玄学。**

**4. 一个音色，百种情绪**
情绪不用分批训练三个模型。软件读你输入的文本自动判断该用什么语气，**你不满意随手就能改**。
一个好音色，就能说出平静、开心、生气、哭腔。

**而且全程不用你碰参考音频** —— 那是软件自己的内务。

## 已经确定的事

| 项 | 决定 |
|---|---|
| **项目名** | **AkiBurger Voice** |
| 形态 | 桌面应用（Web 技术做界面 + 桌面外壳） |
| 引擎 | GPT-SoVITS（本机已装，不另起炉灶，但留替换活口） |
| 语言 | 中、英、日 |
| 范围 | 只做音频，不做视频，不做人声分离 |
| 素材处理 | 半自动 —— 自动识别 + 只让人抽查可疑的 |
| **情绪控制** | **自动判断 + 用户可改**（单音色多情绪，不分批训练） |
| **参考音频** | **用户不接触** —— 软件根据语气自动从训练数据里挑，界面不出现 |
| **情绪的前提** | **高数据拟合** —— 数据里没有的情绪，软件变不出来 |
| **参数设计** | **展示出来 + 教明白**（不走"藏起来防呆"路线） |
| 批量输出 | 一次一句 / 批量整片，**让用户选** |
| 存档策略 | 不用全留，但也不能只留最新 —— 智能保留若干候选 |
| 工作目录 | 代码、输出、素材**全部放在 `D:\Dev\projects` 下**，方便管理和推送 |
| 架构 | 分应用层 / 能力层，两层之间三个标准接口 |
| 代码标准 | 一开始就按开源标准写 |
| 打包文档 | 跑顺了再补 |
