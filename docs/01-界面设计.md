# 界面设计

界面是一个单页应用：左侧竖排菜单切换六个页面，右侧是音色设置，底部是台词输入和合成控件。视觉方向是日系游戏的静态界面，不用持续动画。

## 布局

```
┌──────────┬──────────────────────────────────────────────┐
│ 品牌      │ 顶部：页面标题 + 状态徽章 + 设置按钮           │
│ 01 合成   │                                              │
│ 02 素材   │           主内容区（各页面不同）               │
│ 03 质检   │                              右侧：声の設定   │
│ 04 标注   │                                              │
│ 05 训练   │  ┌────────────────────────────────────────┐  │
│ 06 评测   │  │ 底部对话框：说话人、台词、语言、语气、合成 │  │
│ 引擎状态  │  └────────────────────────────────────────┘  │
│ 教程      │  BACKLOG 抽屉（历史）                        │
└──────────┴──────────────────────────────────────────────┘
```

- 左侧菜单：01 合成、02 素材、03 质检、04 标注、05 训练、06 评测
- 顶部：引擎 / 翻译 / 当前模型 / 版本徽章，右侧齿轮打开设置
- 右侧「声の設定」：当前音色、参考音频、音质微调、预设
- 底部对话框：galgame 风格的说话人牌、台词输入、输入/输出语言、6 种语气、批量与合成按钮
- 左上 LAST TAKE：最近一次合成结果，播放器、波形、下载、设为参考、存预设
- 左下 BACKLOG 与教程入口
- 设置浮层：动效与背景开关、自定义图片、音色名称、模型管理、清理空间

## 视觉

- 亮色为主，蓝色作为主色，粉色作为强调色
- 全屏樱花主视觉，人物在右侧，左侧留给菜单和文字
- 面板用半透明白色玻璃，保证文字可读
- 中文字体使用系统无衬线；标题和台词可以用明朝体；展示字体只用拉丁字符和数字（该字体没有假名）

## 角色状态

背景图有 5 张同构图表情，根据操作切换：

| 状态 | 触发 |
|---|---|
| idle | 默认 |
| thinking | 合成中、评测中、导入/识别中 |
| happy | 合成成功、评测完成、训练成功 |
| sad | 合成失败、训练失败、接口报错 |
| surprised | 切换模型或参考音频 |

背景切换是 120ms 交叉淡入，只有表情变化，人物位置不动。
上传自定义背景或立绘后，表情切换暂停。

## 动效

唯一的页面级动效是切换页面：

- 旧页面淡出并位移 8px，新页面反向滑入，总时长约 240ms
- 一条很细的斜向高光扫过，只做提示，不遮挡内容
- 背景图不参与转场
- 打开「减少动态效果」或关闭设置里的动效开关后，只做 150ms 淡入

没有粒子、没有持续动画、没有 canvas 装饰。波形 canvas 只用来画合成结果的波形。

## 响应式

- 宽度 ≤ 1400 且高度 ≤ 790，或宽度 ≤ 860：进入紧凑模式
- 紧凑模式下，声の設定和设置变成顶栏按钮打开的抽屉，历史也放进抽屉
- 标注、素材等长列表使用内部滚动，避免整页滚动
- 1100 / 860 / 640 宽度下不出现横向滚动

## 素材

- 背景：`src/static/assets/hero-*.webp`，5 张 1920 宽，本地 AI 生成
- 干净底图：`src/static/assets/bg-plain.webp`，上传自定义角色时使用
- 字体：`src/static/fonts/` 下的站酷庆科黄油体（OFL）和许可文件
- 启动器背景：`launcher/assets/bg-*.jpg`，同一套图的裁切版

所有素材随仓库分发，运行时不请求外部图片或字体。
