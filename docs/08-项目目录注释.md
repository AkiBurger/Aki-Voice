# 项目目录注释（v0.3.0 现状）

这份文件给每个目录/文件写一句话说明，方便接手或清理时知道什么能删、什么不能动。
最后更新：2026-10-20（当前工作区状态）。

## 顶层

```
voice-studio/
├─ src/                 源码（后端 + 前端）
├─ data/                本机数据：素材、标注、参考音频、模型注册表（不提交）
├─ outputs/             合成产物与评测产物（不提交，可清理）
├─ logs/                运行日志（可清理）
├─ docs/                项目文档
├─ design-system/       设计规范
├─ launcher/            启动器源码（C# WinForms）
├─ tools/               QA / 生成脚本
├─ AkiBurgerVoice.exe   编译好的启动器（不提交）
├─ 启动.bat             双击启动（调启动器 exe）
├─ 清理痕迹.bat         发布前清理本机痕迹用
├─ config.json          本机配置（端口、引擎路径）
├─ config.example.json  配置模板（提交）
├─ requirements.txt     后端 Python 依赖
├─ README.md            项目说明
└─ LICENSE              MIT
```

## src/backend — FastAPI 后端（端口 8017）

| 文件 | 作用 |
|---|---|
| `app.py` | 主服务：所有 HTTP 接口、静态托管、模型注册/启用、参考音频、维护清理 |
| `engine.py` | 调 GPT-SoVITS 引擎（9880）：健康检查、切权重、合成请求 |
| `data_prep.py` | 素材导入/删除/恢复、扫描、转码、清单维护 |
| `trainer.py` | 训练编排：调 GPT-SoVITS 训练脚本、进度、训练后自动挂权重并设 active |
| `evaluate.py` | 评测：固定测试句、逐句合成打分、写评测历史 |
| `qc.py` | 质检：音频指标 + 文本检查，出报告 `data/qc_report.json` |
| `annotate.py` | 标注：读写 `data/setsuna/setsuna_clean.list` |
| `emotion.py` | 从文本猜语气（平静/开心/悲伤…） |
| `text_split.py` | 长文本切句、中英日混排处理 |
| `translate.py` / `translate_local.py` | 中文→日文翻译（在线/本地回退） |
| `folder_picker.py` | 服务端弹 Windows 文件夹选择框（素材页「浏览…」） |
| `selftest.py` | 15 项自检，结果写 `data/_selftest.txt` |
| `requirements-note.txt` | 环境说明备注 |

## src/static — 纯静态前端（无构建）

| 文件/目录 | 作用 |
|---|---|
| `index.html` | 单页外壳：左侧 01~06 菜单、galgame 对话框、声の設定、设置、BACKLOG、教程 |
| `styles.css` | 全部样式：亮色玻璃、樱花背景、转场、紧凑模式、响应式 |
| `app.js` | 全部交互：切页/转场、合成、批量、模型切换、素材/质检/标注/训练/评测、设置、教程 |
| `assets/` | 主视觉 5 张表情图 `hero-*.webp`、干净底图 `bg-plain.webp`（约 1.5MB） |
| `fonts/` | 本地展示字体（站酷庆科黄油体 + OFL 许可证） |

## launcher — 启动器

| 文件/目录 | 作用 |
|---|---|
| `launcher.cs` | WinForms 启动器：找引擎目录、起 9880、挂权重、起后端、健康检查、打开页面 |
| `build.bat` | 用系统 csc 编译，内嵌 manifest、4 张背景、字体子集 |
| `assets/` | 启动器背景 `bg-*.jpg`（1800×1120）、卡通图标 `app.ico` / `app-icon.png`、DPI manifest、字体子集、字体子集生成脚本 |

编译产物 `AkiBurgerVoice.exe` 在项目根目录，不提交。

## data — 本机数据（不要提交、不要随便删）

| 路径 | 内容 | 能不能删 |
|---|---|---|
| `data/setsuna/wav/` | 你导入的素材 wav（当前 14 段） | 不能，删了要重导 |
| `data/setsuna/setsuna.list` | 原始清单（路径 + 文本） | 不能 |
| `data/setsuna/setsuna_clean.list` | 清洗后的标注清单，训练直接用它 | 不能 |
| `data/setsuna/list_backups/` | 标注清单自动备份 | 可删旧的 |
| `data/setsuna/*.py` | 辅助脚本（训练/ASR/清洗的包装） | 保留 |
| `data/ref/` | 参考音频（默认原声 + 语气库 tones/） | tones 可重建；原声别删 |
| `data/ref/tones_bad_*` | 之前生成的坏语气库备份 | 可删 |
| `data/theme/` | 你上传的自定义背景/立绘（webp） | 可在设置里「恢复默认」 |
| `data/models.json` | 模型注册表：active + 每个权重的显示名 | 不能，删了模型名/启用状态丢 |
| 界面「设置 → 模型管理」 | 列出所有模型，可删除非当前使用的模型（权重进 `data/_model_trash`） | — |
| `data/voice.json` | 音色显示名（如「東馬」） | 可在设置里改 |
| `data/evaluations.json` | 评测历史 | 可在评测页清空 |
| `data/qc_report.json` | 最近一次质检报告 | 可在质检页「清空结果」 |
| `data/_trash/` | 删除素材的回收站（可恢复） | 可在设置「清理空间」清空 |
| `data/_model_trash/` | 删除模型时移出的权重备份（只备份 .pth，不含 GPT） | 确认不要后可删 |
| `data/_disabled_startup/` | 旧的启动禁用标记（历史遗留） | 可删 |
| `data/_selftest.txt` | 自检结果 | 可删 |

## outputs — 运行时产物（不提交）

| 路径 | 内容 | 能不能删 |
|---|---|---|
| `outputs/<时间戳>/` | 每次合成的 wav、波形、meta.json；BACKLOG 历史用它 | 设置「清理空间 → 合成产物」 |
| `outputs/_eval/` | 评测产物 | 保留，跟随评测历史 |

## logs — 运行日志（不提交）

`logs/*.log/*.out/*.err` 是启动器和后端的运行日志，设置「清理空间 → 日志」可清。
`logs/design-*.txt`、`logs/vscode-repair.txt` 是早期排查记录，可删。
