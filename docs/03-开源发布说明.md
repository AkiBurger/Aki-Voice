# 发布说明

当前版本：**v0.3.0**（2026-10）

## v0.3.0 主要变化

- 界面重做：左侧 01~06 菜单、底部台词对话框、右侧音色设置、左上结果面板、左下历史与教程
- 训练完成后自动启用最高轮数模型，模型可以手动启用、改名、删除
- 音色名称可以自定义，界面上的称呼跟着变
- 设置面板增加清理空间（回收站 / 训练缓存 / 合成产物 / 日志）
- 新增六步教程和页面切换动效
- 支持上传自定义背景和角色立绘
- 启动器重做为 galgame 标题画面，支持高 DPI、单实例、失败重试
- 后端路径改为按项目位置自动探测，不再写死作者目录；不符合时可用环境变量覆盖
- 数据目录改为 `data/voice`；旧版本的数据目录也能自动识别

## 升级注意

- 旧版本留下的数据目录不用改名，程序会自动识别
- 训练权重文件名不用改；在「声の設定 → 当前音色」里启用即可
- 旧 `config.json` 可以继续使用
- 如果使用启动器，需要重新运行 `launcher\build.bat` 编译
- 首次启动后如果界面显示旧样式，强制刷新一次（`Ctrl + F5`）

## 已知限制

- 启动器和文件夹选择框只支持 Windows
- 默认按固定目录关系查找 GPT-SoVITS / ffmpeg / HF 缓存，不符合时需要环境变量
- 语气判断是关键词规则，不是语义模型
- 内置翻译只支持中→日，其它方向需要 Ollama
- 评测分数是声纹相似度，不评价自然度
- 没有自动更新和安装包
- 声音克隆的版权与合规责任由使用者承担

## 发布流程

1. 跑 `src/backend/selftest.py` 和 `tools/ui_smoke.js`，确认全部通过
2. 更新 `docs/assets` 截图和本文件的版本说明
3. 检查 Git 状态：不要包含 `data/`、`outputs/`、`logs/`、模型权重、exe、密钥
4. 提交并推送
5. 打标签并创建 Release：

```bat
git tag v0.3.0
git push origin v0.3.0
```

Release 页面说明可以直接用本文件的内容。源码压缩包由 GitHub 自动生成。

## 构建启动器（可选）

需要 .NET Framework 4.x（Windows 自带 csc.exe）：

```bat
cd launcher
build.bat
```

产物是项目根目录的 `AkiBurgerVoice.exe`。启动器会内嵌 `launcher/assets/` 下的背景图、图标和字体子集，所以这些文件必须存在。

exe 是否随 Release 发布由维护者决定；仓库本身不包含 exe。
