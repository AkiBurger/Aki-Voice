# 一、十一条设计原则

这是整个界面的宪法。任何设计有疑问，回来对这几条。

## 1. 主流程永远可见

左侧导航按流水线分组常驻：**创作**（合成）、**训练流水线**（素材 → 质检 → 标注 → 训练）、**质量**（评测）。
随时知道自己在哪一页、下一步是什么，不用记路径。

```
┌──────────┬──────────────────────────────┐
│ 创作      │  顶部状态条：页面标题 · 模型 · 翻译 · 版本 │
│  ▸ 合成   ├──────────────────────────────┤
│ 训练流水线 │                              │
│  素材     │        当前页内容区            │
│  质检     │    （单页切换，内部滚动，        │
│  标注     │      一次只看一页）            │
│  训练     │                              │
│ 质量      │                              │
│  评测     │                              │
└──────────┴──────────────────────────────┘
```

- 当前页：高亮（`aria-current="page"` + 3px 左竖条 + 微亮背景）
- 其它页：灰显但始终可点，随时切换
- **不能出现"我不知道现在该干什么"的状态**

## 2. 给结论，不给数据

| ❌ 不要这样 | ✅ 要这样 |
|---|---|
| 信噪比 12.3 dB | 背景有杂音，建议重录 |
| epoch 12, loss 0.0231 | 训练完成，效果比上一版好 |
| 相似度 0.8134 | 相似度还可以 |
| CUDA out of memory | 显存不够了 |

**专业数据可以藏在"详情"里，但主界面说人话。**
评测页的原始分数会展示（用户就是要对比版本），但一定同时给出「很像 / 像 / 一般 / 不像」和一句人话结论。

## 3. 参数要展示，要教明白

**不采用"把高级参数藏起来防呆"的做法。**

本软件的目标用户是**想练出好声音的人**，不是只想点一下就出结果的普通用户。藏起来反而挡住他们。

| 做法 | 说明 |
|---|---|
| **参数可见** | 训练参数、高级参数在训练页常显；合成页高频参数（模型、预设）常显 |
| **每个参数配一句人话说明** | 讲清是什么、什么时候该动、动了会怎样 |
| **另附参数含义文档** | 系统性的说明，不只是一句话提示 |
| **默认值即推荐值** | 不懂的人直接用，效果也是好的 |

> v0.2 的折中：合成页「音质微调」默认收起（把首屏留给"写台词 → 合成"这条主路径），
> 一键展开后温度和随机种子都可见可调，并各带一句人话说明；训练页的参数则全部常显。
> 收起 ≠ 藏起来，原则仍然成立。

## 4. 每一个等待都有交代

任何超过 3 秒的操作，必须显示三件事：

```
在做什么     正在识别第 47 / 289 段
还剩多久     约剩 2 分钟
能不能中断   [ 取消 ]
```

**禁止**：只转圈圈、只显示"处理中"、进度条卡在 99% 不动。

> v0.2 落实：素材导入 / 识别清洗 / 训练 / 评测 / 合成都有一行状态文字 + 进度条；
> 长任务（训练、识别清洗）在后台跑，页面可切走，回来后进度和日志还在。

## 5. 危险操作能撤销

| 操作 | 保护方式 |
|---|---|
| 删除音频段 | 移入回收站，可点「恢复删除」找回；删除前 confirm |
| 清空所有素材 | 移到回收站（不是真删），可恢复；清空前 confirm |
| 清空历史 | 二次确认，并明确提示"音频文件会一起删除、无法恢复" |
| 覆盖已训练模型 | 训练默认「从零训练」：先把旧 checkpoint 备份到 `_backups`，不会被静默覆盖 |
| 清空质检 / 标注结果 | 不弹确认（可重跑 / 标注有自动备份），执行后 toast 提示 |

**凡是不能撤销的，必须二次确认。**

## 6. 高频操作键盘流

标注、合成这两个高频环节。

| 场景 | 快捷键（v0.2 已实现） |
|---|---|
| 合成 | `Ctrl+Enter` 立即合成（防重复：进行中再按会 toast 提示） |
| 合成 | `空格` 播放 / 暂停结果音频（焦点不在输入框、结果区可见时） |
| 通用 | `Tab` 焦点顺序 = 视觉顺序；按钮用 `Enter` / `空格` 触发 |

> 标注的纯键盘流（空格播放 / 回车确认 / → 跳过 / Del 删除）是设计目标，v0.2 尚未实现，
> 属于后续版本的交互增强，见第十节。

## 7. 长任务不锁界面

训练一小时，这中间必须能去做别的。

```
✗ 错误做法：弹出模态框，训练完才能关
✓ 正确做法：训练进后台，页面可切走，进度和日志都在
```

**v0.2 现状**：训练、素材识别清洗都在后台线程 / 子进程跑，界面不锁；
进入训练页能看到阶段进度、已用时和日志；训练完成自动挂载新权重。
常驻全局任务栏（任何页面都能看到后台任务）是设计目标，尚未实现。

## 8. 出错说人话

每条错误必须包含三部分：

```
出了什么问题    显存不够了
为什么会这样    显存装不下这么多任务
该怎么办        先别急着继续，去把别的任务停掉
```

**最后一项最重要 —— 给出可点的解决办法，不要只告诉用户"错了"。**

> v0.2 实现：危险/失败用红色提示卡（标题 = 什么问题，说明 = 下一步怎么办）；
> 引擎未就绪的提示还会区分"后端没起来"和"后端在、引擎没加载完"两种情况。

## 9. 深色为主

理由：

- 配音常在晚上做
- 波形、数值、对比界面在深色下更清晰
- 长时间看不累

**v0.2 决策：只做深色主题**（`color-scheme: dark`，原生控件跟随深色）。
不做浅色切换 —— 同一套 token 同时维护两套主题的成本不值得，先把深色做扎实。

## 10. 一处一个主按钮

每一屏有**一个**视觉上最重的按钮，就是这一步最该点的那个。

```
[ 合成 ]       ← 全站唯一主 CTA，暖橙实心
[ 批量合成 ]    ← 次要，描边
[ 清空 ]       ← 弱化，纯文字
```

v0.2 全站只保留一个暖橙色主按钮：合成页的「合成」。

## 11. 空状态要教人做事

第一次打开，**不给人一片空白**，而是告诉他下一步做什么：

| 页面 | 空状态引导 |
|---|---|
| 素材 | "还没有训练数据。选一个音频文件夹，点「扫描」→「① 导入音频」→「② 识别 + 清洗」。" |
| 合成历史 | "还没有合成记录。合成的音频会出现在这里。" |
| 预设 | "还没有预设。合成出满意的结果后，点「存成预设」。" |
| 评测历史 | "还没有评测记录。点「开始评测」跑第一次。" |

**新手不该面对空白，也不该猜"我该点哪个"。**

# 二、视觉规范（v0.2 实现）

## 2.1 权威文件

所有颜色、字体、组件、动效、图标规范以
[`design-system/akiburger-voice/MASTER.md`](../design-system/akiburger-voice/MASTER.md) 为准。
本节只列实现时实际使用的 token 和尺寸，方便查对。

## 2.2 颜色 token

定义在 `src/static/styles.css` 的 `:root`，组件里禁止写裸 hex。

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0B0B18` | 页面底 |
| `--surface-1` | `#14142A` | 侧栏 / 顶栏 / 页脚 |
| `--surface-2` | `#1B1B30` | 卡片 |
| `--surface-3` | `#27273B` | 输入框底 / 悬停 / 波形底 |
| `--border` | `#2C2C48` | 常规边框 |
| `--border-strong` | `#4338CA` | 选中 / 强调边框 |
| `--fg` | `#F8FAFC` | 主文字 |
| `--fg-muted` | `#94A3B8` | 说明文字、次要信息 |
| `--fg-faint` | `#64748B` | 占位符 / 禁用（不承载关键信息） |
| `--primary` | `#6366F1` | 品牌 / 激活 / 链接 / 波形未播放部分 |
| `--primary-soft` | `rgba(99,102,241,.14)` | 激活态背景 |
| `--accent` | `#F97316` | 全站唯一主 CTA / 焦点环 / 波形播放进度 |
| `--on-accent` | `#0F172A` | 暖橙底上的文字 |
| `--success` / `--warning` / `--danger` | `#22C55E` / `#F59E0B` / `#EF4444` | 状态徽标、等级、危险按钮 |

**用色原则：颜色只用来传达状态，不做装饰。** 界面整体偏深靛蓝灰，只有"需要你注意的地方"才出现颜色。

## 2.3 字体与字号

```css
--font-sans: "Inter", "Segoe UI", system-ui, "Microsoft YaHei UI", sans-serif;
--font-mono: "JetBrains Mono", "Cascadia Mono", Consolas, monospace;
```

> 不加载任何外部字体（离线可用优先）：装了 Inter 就用 Inter，没装自动回退到 Segoe UI / 微软雅黑。

| 层级 | 字号 / 字重 | 用途 |
|---|---|---|
| Display | 40px / 700 / -1.2px | 评测大分数 |
| H1 | 24px / 600 / -0.4px | 内容区页面标题 |
| H2 | 16px / 600 | 卡片标题 |
| Body | 14px / 400 / 行高 1.55 | 正文 |
| Input | 15px / 400 | 台词输入框 |
| Label | 12px / 500 / +0.02em | 字段名、按钮小字 |
| Caption | 12px / 400 | 辅助说明 |
| Mono | 12.5px / 400 | 日志、随机种子、分数、耗时 |

数字统一 `font-variant-numeric: tabular-nums`（分数、时间、进度不跳动）。

## 2.4 间距 / 圆角 / 阴影 / 动效

- 间距阶梯：`4 / 8 / 12 / 16 / 24 / 32 / 48`（token `--s1`~`--s7`）
- 卡片内边距 20px；卡片间距 16px；页面左右 32px（窄屏 24/16px）
- 圆角：卡片 `12px`（`--radius-card`）、按钮/输入 `8px`（`--radius-control`）、胶囊 `999px`
- 阴影：卡片几乎不用；`--shadow-sm` 用于主按钮，`--shadow-md` 留给浮层
- 动效：`150ms cubic-bezier(.2,.6,.2,1)`，只动颜色 / 背景 / 边框 / 透明度；**禁止 hover 位移**造成布局跳动
- 必须支持 `@media (prefers-reduced-motion: reduce)`（v0.2 已加全局兜底）

## 2.5 组件规范（实现值）

| 组件 | 规格 |
|---|---|
| 主按钮（合成） | 高 40px，`--accent` 底 + `--on-accent` 字，600 字重，全站唯一 |
| 次要按钮 | 高 32px，`--surface-2` 底 + `--border` 边 |
| 小工具 / Ghost | 高 28px，透明底，hover `--surface-3` |
| 危险操作 | 纯文字按钮 + `--danger`（删除 / 清空），不做大色块 |
| 输入框 / 下拉 / 种子输入 | 高 34px（标注页行内输入 32px），背景 `--surface-3`，focus 2px ring |
| 卡片 | `--surface-2` 底、1px 边框、12px 圆角、20px 内边距 |
| 列表行 | 高 36px（标注页 40px），hover 提亮，操作按钮靠右 |
| 徽标 | 高 20px、11px 字、胶囊圆角、语义色 12% 透明底 |
| 进度条 | 轨道 6px，填充 `--primary` |
| 波形画布 | 高 72px、`--surface-3` 底、`--primary` 填充、`--accent` 表示已播放进度 |
| A/B 按钮 | 32px 圆形 ghost 按钮 |

## 2.6 图标（内联 SVG sprite）

- 禁止 emoji 当图标；全部使用 `index.html` 顶部隐藏的 `<svg class="svg-sprite">` + `<symbol id="i-xxx">`。
- 用法：`<svg class="icon" aria-hidden="true"><use href="#i-play"/></svg>`，`.icon` 默认 16px。
- v0.2 内置 32 个符号：`alert-triangle / chart / check / chevron-down / clock / cpu / database / download / eraser / eye / filter / folder-upload / info / layers / mic / music / pause / pencil / play / plus / refresh-cw / rotate-ccw / save / search / settings / square / star / translate / trash-2 / volume-2 / waveform / x`
- 导航图标 18px；纯装饰图标 `aria-hidden="true"`；图标按钮必须带 `title` + `aria-label`。

## 2.7 无障碍

- 页面首个可聚焦元素是「跳到主内容」链接（`#main`）
- 全局 `:focus-visible`：2px `--ring` 外框 + 2px offset
- 侧栏 `<nav aria-label="主导航">`；当前页 `aria-current="page"`；内容区 `<main id="main">`
- 图标按钮 `aria-label`；纯装饰图标 `aria-hidden="true"`
- `color-scheme: dark` 让原生 select / audio / 滚动条深色化
- 支持减少动态效果偏好；语义色同时配文字（不单靠颜色）

## 2.8 响应式断点

| 断点 | 行为 |
|---|---|
| ≥1440px | 基准：侧栏 220px + 内容 max-width 1160 居中 |
| 1100–1439px | 侧栏 220px；合成页右栏收窄到 320px |
| <1100px | 侧栏收成 64px 图标版（`title` 提示），隐藏品牌文字、分组标题、英文副标题，状态区只留圆点 |
| <860px | 合成页两栏变单栏；顶栏 52px，隐藏次要徽标（翻译 / 版本）；按钮一行最多 2 个；评测大分数降到 36px |
| <620px | 卡片头可换行；训练/高级参数单列；结果操作按钮整行 |

不允许出现横向滚动条。

# 三、应用外壳

## 3.1 结构

```
┌──────────────────────────────────────────────────────────────┐
│ sidebar 220px        │ topbar 56px：页面标题 · 模型 · 翻译 · 版本 │
│  brand（logo+v0.2.0）├────────────────────────────────────────┤
│  nav：创作/训练流水线/质量 │ content-scroll（内部滚动）              │
│                      │   page（max-width 1160 居中）              │
│                      │     page-head + 当前 view                 │
│  sidebar-status      ├────────────────────────────────────────┤
│  引擎/模型/翻译       │ app-footer：本地运行提示 · 引擎在线          │
└──────────────────────────────────────────────────────────────┘
```

- 外壳 `.app-shell`：CSS Grid 两列（`--sidebar-w` 220px + 自适应），整屏 `100vh/100dvh`。
- 右侧 `.app-main`：纵向 flex（顶栏 + 内容 + 页脚）。
- 只有内容区滚动（`.content-scroll`），侧栏、顶栏、页脚固定。

## 3.2 左侧导航

- **品牌区**：纯 CSS 圆点 logo（20px，`--primary`）+ "AkiBurger Voice" + 小字版本号 `v0.2.0`。
- **分组**：
  - **创作**：合成（Synthesize）
  - **训练流水线**：素材（Materials）、质检（QC）、标注（Annotate）、训练（Train）
  - **质量**：评测（Evaluate）
- **导航项**：高 34px，图标 18px + 中文名（13.5px）+ 右侧英文小字（11px）。
- **激活态**：左侧 3px `--primary` 竖条 + `--primary-soft` 背景 + 文字 `--fg`；`aria-current="page"`。
- **底部状态区**：
  - 引擎状态徽标（`#engineBadge`：引擎就绪 / 检查中 / 未连接）
  - 当前音色模型（`#sideModelName`）
  - 翻译引擎状态（`#sideTranslator`：可用 / 未连接）
- 窄屏（<1100px）收成 64px 图标版，只留图标 + hover 提示。

## 3.3 顶部状态条

- 高 56px，`--surface-1` 底，1px 下边框。
- 左侧：当前页面标题（`#pageTitle`，14px/600，随导航切换：语音合成 / 训练模型 / 评测打分 / 素材 / 质检 / 标注）。
- 右侧 3 个 20px 小徽标：
  - **模型** `#topModelBadge`（当前音色名）
  - **翻译** `#translatorBadge`（可用 / 未连接）
  - **版本** `v0.2.0`
- <860px 隐藏"翻译 / 版本"两个次要徽标。

## 3.4 内容区与页脚

- `.page`：max-width 1160px 居中，padding 24px 32px 48px。
- 页面头：页面标题（24px/600）+ 一句说明（14px `--fg-muted`，max-width 840px）。
- 页脚：一行小字 —— "本地运行，你的声音和文字不会离开这台电脑 · 引擎在线/离线"（`#footEngine`）。

## 3.5 页面切换

- 六个页面各一个 `.view` 容器（`view-synth / view-material / view-qc / view-annotation / view-train / view-eval`），**同一时刻只显示一个**，其余加 `.hidden`。
- 导航按钮带 `data-view`；切换时同步：视图显隐、导航高亮、`aria-current`、顶栏标题、`document.title`、URL hash（`#train` 等）、内容区滚动复位。
- 进入某页时按需加载该页数据（素材 / 质检 / 标注 / 训练 / 评测各自懒加载）。
- 直接带 hash 打开（如 `127.0.0.1:8017/#eval`）会定位到对应页；默认是合成页。

# 四、合成页（日常主页面）

## 4.1 两栏布局

```
┌───────────────────────────────────────────────┬──────────────────┐
│ 左栏 synth-main（自适应）                       │ 右栏 synth-side    │
│  1. 语言卡（输入语言 → 输出语言）                 │  340px（窄屏 320）  │
│  2. 台词卡（textarea + 字数/预计时长/清空）        │  A. 模型卡         │
│  3. 语气卡（自动判断提示 + 7 个语气按钮）           │     - 当前音色下拉  │
│  4. 行动卡（合成主按钮 + 批量合成）                 │     - 试听 / 改名  │
│  5. 合成中状态 / 批量合成面板（按需出现）            │  B. 音质微调（折叠）│
│                                                │     - 稳定度       │
│                                                │     - 随机种子     │
│                                                │  C. 预设卡         │
├───────────────────────────────────────────────┴──────────────────┤
│ 全宽：错误提示（按需）→ 结果卡（波形 + A/B）→ 历史记录卡              │
└──────────────────────────────────────────────────────────────────┘
```

- 布局：`.synth-grid` 两列（`minmax(0,1fr) 340px`，1100–1439px 时 320px），<860px 变单列。
- 左栏是"写→选→合成"的主路径；右栏是"模型 + 微调 + 预设"这类低频但重要的控制项。
- 结果卡、历史卡在下方全宽，不挤占主路径。

## 4.2 交互流程

1. **语言**：输入语言（中文 / 日文 / 英文）→ 输出语言（中文 / 英文 / 日文）。
   两者不同时自动翻译（中→日有内置模型兜底；其它方向需要 Ollama），下方一句话说明当前会在做什么。
2. **台词**：多行输入；实时显示字数、预计朗读时长（估算值，明确标注"时长不受精确控制"）；可一键清空。
3. **语气**：自动从文本判断（判断结果会显示"自动判断为「X」"+ 置信度），也可手动点选
   平静 / 开心 / 悲伤 / 生气 / 惊讶 / 害怕 / 自动。
   > 语气会真的改变声音：生成过语气参考库（`data/ref/tones/`）时，合成按语气自动切换参考音频，
   > 参考音频与参考文本始终是日语；没有语气库时退回默认参考音频。生成方式见 README 常见问题 9。
4. **合成**：主按钮「合成」（Ctrl+Enter，进行中防重复点击）；引擎未就绪时按钮禁用并显示黄色提示卡。
5. **结果**：合成成功后自动出现结果卡，播放器、波形、下载、存预设、再来一次、翻译核对。
6. **错误**：红色提示卡（标题 + 一句人话说明），例如显存不足、翻译失败、引擎报错。

## 4.3 结果区（v0.2 新增波形 + A/B）

结果卡（`#resultSection`）从上到下：

| 区块 | 说明 |
|---|---|
| 卡片头 | 标题「结果」+ 右侧操作：下载 / 存成预设 / 再来一次 |
| 翻译核对 | 跨语言时显示"翻译后实际朗读的文本"（`#translatedBox`），方便核对译文 |
| 播放器 | 原生 `<audio controls>`（`#resultAudio`） |
| **波形图** | `<canvas id="waveCanvas">`，高 72px；取音频峰值画 180 根竖条，未播放用 `--primary`、已播放部分用 `--accent` 随播放进度重绘；解码失败静默降级（不影响播放） |
| **A/B 对比** | `#abCompare`：保留最近两次合成结果，A = 上一次、B = 这一次；只有 ≥2 条时出现；点 A/B 用统一播放器试听并显示"正在播放：A/B"；换一次合成后 A 变旧、B 变新 |
| 元信息 | 语气 / 耗时 / 时间等（`#resultMeta`） |

## 4.4 批量合成

- 从行动卡右侧「批量合成」展开（`#batchPanel`，默认收起）。
- 每行一句，逐句合成；行首可写「语气｜台词」单独指定这一句的语气，否则用"默认语气"下拉。
- 有开始 / 停止按钮、进度与逐条结果列表，结果可单独试听。

## 4.5 历史记录

- 只显示最近 20 条**真正的合成记录**（以 `outputs/<时间戳>/meta.json` 为准，手动放进去的对比样本不算）。
- 每行：播放按钮、台词文本、语言 / 语气标签、时间、下载、删除。
- 统一播放器：点任何一条播放前先停止其它音频（含结果播放器、预览、批量、素材/标注/质检/评测里的试听），当前播放行高亮。
- 「清空历史」需二次确认，并明确提示音频会一起删除、无法恢复。

# 五、训练流水线四页

四页的列表统一规格：行高 36px（标注页 40px）、hover 提亮、操作按钮靠右、长列表最多渲染 300 条并提示总数。

## 5.1 素材页

1. **训练素材卡**：
   - 三步说明：选文件夹 → 导入音频 → 识别 + 清洗。
   - 「浏览…」调 Windows 原生文件夹选择框（`#browseBtn`），也可直接粘贴路径。
   - 「扫描」显示文件数 / 总时长 / 已导入数；「① 导入全部音频」「② 识别 + 清洗」带 confirm 确认。
   - 导入 / 识别期间显示进度条 + 实时日志（`#dataJob`）。
   - 数据状态提示会明确说"可以训练"还是"还没识别清洗"。
2. **已导入的素材卡**：
   - 统计：已导入 N 段 · 总时长约 M 分钟。
   - 操作：恢复删除（从回收站按批次找回）/ 刷新 / 全部清空。
   - 每行：播放、文件名、时长、删除（单条删除前 confirm，移到回收站）。

## 5.2 质检页

- 卡片头：清空结果 / 开始质检。
- 结果摘要（通过 / 警告 / 不合格数量）+ 筛选（全部 / 警告 / 不合格）。
- 每行：播放、等级徽标、文件名、问题原因（多个问题用"；"连接）。
- 没有问题时显示"很好：没有发现问题样本"。
- 换模型或换数据后，旧质检结果自动清空（避免对不上号）。

## 5.3 标注页

- 卡片头：清空列表 / 刷新。
- 统计：共 N 条标注 · 缺文本 / 过短 / 过长 / 音频缺失数量。
- 筛选：全部 / 文本过短（<4 字）/ 文本过长（>60 字）。
- 每行：播放、文件名 · 时长、文本输入框、保存按钮（保存成功按钮短暂变"已保存"）。
- 保存会写回 `setsuna_clean.list`，并自动备份（保留最近 10 份）。
- 换模型或数据变化时，标注列表会清空并提示「点刷新重新读取」，避免旧结果对不上号。

## 5.4 训练页

按卡片纵向分区（`.train-stack`）：

| 卡片 | 内容 |
|---|---|
| 本次训练 | 数据概览（多少段音频 / 多少分钟 / 清洗后多少条标注，是否就绪）+ 状态徽标（空闲 / 训练中 / 完成 / 失败） |
| 训练参数 | 音色模型轮数（默认 6）、韵律模型轮数（默认 8）、音色批量（2）、韵律批量（4）、**从零训练**（默认勾选） |
| 高级参数 | 音色/韵律保存间隔、音色/韵律学习率（0 = 用默认值）、训完自动评测 |
| 开始训练 | 人话说明 + 开始 / 停止按钮；运行中显示阶段、进度条、已用时、实时日志 |

- 训练在后台跑，可以切去别的页面；回来进度和日志仍在。
- 「从零训练」勾选 = 备份旧 checkpoint 后从预训练底模重训；取消 = 在现有权重上续训。
- 停止训练需二次确认，会连带结束训练子进程，避免留下占显存的孤儿进程。

# 六、评测页

## 6.1 页面结构

1. **评测对象卡**：当前模型、参考音频、测试句构成（5 句日文 + 3 句中文 + 3 句英文，共 11 句），说明"分数只反映像不像本人，不评价好不好听"。
2. **本次评测卡**：
   - 「开始评测」按钮 + 进度提示（约 1.5 分钟）。
   - 结果：**大分数卡**（Display 40px 数字 + 等级 + 模型名）→ 人话结论（分语言小结 + 建议）→ 分语言小分 chips → 图例（≥0.78 很像 / 0.65~0.78 像 / 0.50~0.65 一般 / <0.50 不像）→ 筛选（全部 / 只看不够像的）→ 逐句明细（播放、文本、分数、等级）。
3. **历史评测**：最近 20 次，每行显示分数、等级、模型、时间，方便跨版本对比。

## 6.2 分数语义

- 分数是**声纹余弦相似度**（0~1，1.000 = 同一个声音），不是主观好听程度。
- 分档：`≥0.78 很像` / `≥0.65 像` / `≥0.50 一般` / `<0.50 不像`；分数语义色同步（绿 / 蓝 / 橙 / 红）。
- 跨语言（中 / 英）分数通常低于本人语言（日），属正常现象。

# 七、错误、提示与空状态

## 7.1 两类提示卡

| 类型 | 位置 | 内容结构 |
|---|---|---|
| `notice-warn`（黄色） | 合成页顶部 | **引擎未就绪**：区分"后端不可达 / 后端在但引擎没起来 / 健康检查失败"三种文案，附「重试连接」 |
| `notice-danger`（红色） | 合成页顶部 | **操作失败**：标题说问题（如"合成失败""删除失败"），说明写下一步怎么办 |

原则：**先说什么问题，再说怎么办；错误信息必须是人话。**

## 7.2 轻提示（toast）

- 底部居中的短提示，约 1.8 秒自动消失。
- 用于成功/中性反馈：预设已保存、已套用预设、已从回收站恢复 N 段素材、质检结果已清空、正在合成中请稍等。

## 7.3 空状态

| 场景 | 提示文案 |
|---|---|
| 没有素材 | 还没有导入任何素材 / 还没有训练数据，按三步走 |
| 还没扫描 | 还没扫描。填好路径后点「扫描」看看有多少素材 |
| 还没质检 | 还没检查过。点「开始质检」，几百段音频大约十几秒 |
| 没有标注 | 共 0 条标注（列表空）/ 没有符合条件的条目 |
| 没有训练数据 | 还没有训练数据。选一个音频文件夹…（引导三步） |
| 没有合成记录 | 还没有合成记录。合成的音频会出现在这里 |
| 没有预设 | 还没有预设。合成出满意的结果后，点「存成预设」 |
| 没有评测记录 | 还没有评测记录。点「开始评测」跑第一次 |
| 引擎未就绪 | 声音引擎还没就绪 + 具体原因 + 重试连接 |

## 7.4 危险操作保护（实现值）

| 操作 | 确认 | 可恢复性 |
|---|---|---|
| 删除单条素材 | confirm | 移到回收站，可恢复 |
| 清空全部素材 | confirm | 移到回收站，可恢复 |
| 清空历史 | confirm（明确说不可恢复） | 不可恢复 |
| 停止训练 | confirm | 已训练阶段保留，本次不出完整模型 |
| 导入 / 识别清洗 | confirm（提示耗时） | 识别前自动备份标注 |
| 清空质检 / 标注结果 | 无确认（toast 反馈） | 质检可重跑；标注有自动备份 |

# 九、技术实现

## 9.1 现状

| 能力 | 实现方式 |
|---|---|
| 页面技术 | 纯静态 HTML + CSS + 原生 JS，**无构建步骤、无框架、无 CDN/外部字体**（离线可用） |
| 样式体系 | CSS 自定义属性（设计 token）+ Grid/Flex；组件里不写裸 hex |
| 图标 | 内联 SVG sprite（`<symbol>` + `<use>`） |
| 页面切换 | 六个 `.view` 容器，JS 显隐；导航 `data-view`；URL hash 深链接 |
| 波形 | `<canvas>` + `fetch(wav)` → `AudioContext.decodeAudioData` → 峰值包络绘制；随 `timeupdate` 重绘播放进度 |
| A/B 对比 | 保留最近两条结果 URL，复用统一播放器（`new Audio`）；A = 旧、B = 新 |
| 语气参考音频 | 合成时按语气从 `data/ref/tones/tones.json` 挑一条参考（含对应日文参考文本），参考音频/文本始终日语；没有语气库时退回默认参考音频 |
| 引擎状态 | 每 12 秒轮询 `/api/health`，断线自动提示、恢复后自动刷新模型与历史 |
| 本地偏好 | 预设存 `localStorage`（读写有 try/catch，失败给人话提示） |
| 响应式 | CSS 媒体查询四档断点（1440 / 1100 / 860 / 620） |
| 无障碍 | 跳转链接、`:focus-visible`、`aria-current`、`aria-label`、`color-scheme: dark`、减少动效偏好 |

## 9.2 未采用的技术（与早期设想的差异）

| 早期设想 | v0.2 实际 |
|---|---|
| WebSocket / SSE 推实时进度 | 轮询 `/api/health`（12s）与各接口返回的进度字段 |
| WebAudio 无缝对比播放 | 原生 `<audio>` 播放（A/B 有起播延迟，够用） |
| 数据地图（几百个方块，虚拟滚动） | 未实现，用列表 + 筛选 |
| 拖拽文件夹导入 | 未实现，用「浏览…」按钮 / 路径输入 |
| 浅色主题 | 未实现，仅深色 |
