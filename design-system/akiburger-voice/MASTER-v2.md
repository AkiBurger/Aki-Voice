# AkiBurger Voice · 视觉规范 v2「アニメ・ダイナミック」

> ## v2.1 修订（用户决策，优先于下文冲突处）
>
> 用户明确：**回滚成「3 + 2」= 二次元动漫画风（碧蓝档案式）+ P5 页面动感**，去掉「1 = 星穹铁道式深空/星尘/流光」。并且实测**背景星尘 Canvas 是唯一卡顿源**（开 22fps / 关 60fps），因此：
>
> 1. **删除背景 Canvas 粒子**（`#bgParticles` 及其 rAF 循环）。背景改用**纯静态 CSS 纹理**：半调网点 + 斜纹 + 少量纯 transform 装饰（≤4 个元素，GPU 合成，不做 blur/rAF）。
> 2. **去掉星轨/极光光斑/深空glow**；保留亮色底，但整体转向**漫画/赛璐璐风**：
>    - 2px 墨线描边（`#1B2437`）+ 硬投影（`4px 4px 0` 同色系），替代柔和模糊阴影；
>    - 半调网点、斜线速度线、漫画分镜框、贴纸标签、对话气泡；
>    - 主色蓝 `#2563EB`，强调红 `#E11D48`（P5 冲击色）、黄 `#FFC53D`、粉 `#FF7AA8`；
>    - 卡片可保留白底，但必须有墨线 + 硬投影，不做玻璃拟态/backdrop-filter。
> 3. **P5 页面动感**：页面转场 = 斜切黑/白分镜面板快速扫过（≤320ms）+ 内容 8px 上滑；成功用"贴纸拍上"（scale 1.15→1 + 硬投影落位）；失败轻微 shake；按钮 press 时硬投影缩到 1px。全部只用 transform/opacity。
> 4. **性能红线（必须实测达标）**：1440×900 下静止与转场期间 **≥55fps**（本机 Chrome/Edge，关 GPU 加速也要 ≥50）；禁止全屏 rAF Canvas、禁止 backdrop-filter、禁止动画 blur/box-shadow、同时动画元素 ≤20；页面隐藏必须暂停所有动画。
> 5. **内容修正**：评测页文案改为「固定 11 句测试台词（5 日文 + 3 中文 + 3 英文，与训练集无关）」；素材占位路径改通用示例。
> 6. 看板娘保留并升级为**漫画/赛璐璐式**（墨线描边、平涂+硬阴影），位置右下角；点她出**对话气泡**（漫画气泡框），不再是普通 toast。

## 0. 一句话

**白昼学园 + 霓虹星尘**：亮色底（天空蓝白）承载日常操作，深海军蓝的「播放器 HUD」承载结果与音频，斜切色块和流光制造动感，一个原创几何少女看板娘负责情绪反馈。

## 1. 设计原则（v2 增补）

1. **明亮但不刺眼**：大面积浅色（#EEF4FF 系），深色只用于"媒体/结果 HUD"和强调块，形成层次而不是整页暗。
2. **动感必须可关**：所有位移/粒子/转场受 `prefers-reduced-motion` 与"动效强度"设置控制；动效不得阻塞输入。
3. **可玩不是闹**：角色和动效服务于"现在发生了什么"（加载/合成中/成功/失败），不做无意义装饰。
4. **斜切与贴纸**：P5 式斜切用于 Hero、CTA、章节标题和转场；贴纸/标签用于状态和成就，但保持信息层级。
5. **日语内容不进展示字体**：展示字体只覆盖中文/拉丁，日文台词一律用正文无衬线，避免混排断裂。

## 3. 字体

- 展示字体：`ZCOOL QingKe HuangYou`（站酷庆科黄油体，OFL，已放 `src/static/fonts/zcool-qingke-huangyou.woff2`）。
  - 用途：LOGO、页面 H1、主按钮、卡片标题、徽章大字、启动器。
  - **不要**用于正文、日文台词、输入框。
- 正文：系统无衬线（Segoe UI / 微软雅黑）。
- 数字（分数、时长、日志）：`--font-mono`，tabular-nums。

## 4. 形态语言（P5 斜切 + 二次元贴纸）

- **Hero 区**：页面标题下方一条斜切色块（`clip-path: polygon(0 0, 100% 0, 96% 100%, 0 100%)`）+ 极光渐变；标题字母可 -2° 倾斜。
- **主 CTA**：斜切右端 12px，渐变 `linear-gradient(100deg, #3D7BFF, #7B5CFF 55%, #FF6FA5)`，hover 有流光扫过（伪元素 translateX），press 缩到 .97。
- **卡片**：白面 + 1px `--line` + `--shadow-card`；hover 上浮 2px + 顶部 2px 渐变条出现。
- **标签/徽章**：小圆角贴纸，可选旋转 -2°~2°（仅装饰性标签，状态徽章不旋转）。
- **结果 HUD**：深海军蓝面板，顶部 2px 渐变光条，波形用 `--primary`/`--accent` 双色，播放器控件深色化。
- **网点/斜纹**：`repeating-linear-gradient(45deg, rgba(61,123,255,.05) 0 2px, transparent 2px 8px)` 只做背景纹理，不压在文字下。

## 5. 动效语言（强但有边界）

| 场景 | 动效 | 时长 | 备注 |
|---|---|---|---|
| 页面切换 | P5 斜切擦除：两层斜切块从右向左扫过，内容 12px 上滑淡入 | 320ms | `reduced-motion` 时只淡入 |
| 启动 Splash | LOGO 斜切入场 + 星尘散开 + 进度细线，1.2s 后消失 | 1.2s | 每个会话只播一次（sessionStorage） |
| 背景粒子 | Canvas 星尘 60~90 粒子，缓慢漂移 + 鼠标视差 | 常驻 | 可关；页面隐藏时暂停；dpr≤2 |
| 主 CTA hover | 流光扫过 + 轻微放大 1.02 | 200ms | |
| 按钮 press | scale(.97) + 内阴影 | 120ms | 所有按钮 |
| 进度条 | 斜纹流动 + 末端光点 | 常驻 | 训练/批量/评测 |
| 合成成功 | 结果 HUD 从下方 16px 弹入 + 星点爆开（canvas 或 CSS 粒子，≤12 个） | 300ms | |
| 看板娘 | 待机呼吸/眨眼；合成中"哼唱"口型+音符；成功跳跃；失败垂头 | 3s 循环/事件 | 可关；<860px 隐藏 |
| 数字变化 | 分数/时长滚动计数 | 400ms | reduced-motion 直出 |
| 侧栏切换 | 激活胶囊滑动（位置过渡） | 220ms | |

**红线**：不做全屏闪白、不做超过 400ms 的阻塞转场、不在输入时抖动、粒子总 CPU < 5%。

## 6. 角色看板娘「アキ」

- 原创几何少女：深蓝短发、蓝色发带、耳机、水手领；用 SVG 手绘（无版权角色）。
- 位置：右下角固定，尺寸 132×196（>1100px），1100~860 缩到 96×144，<860 隐藏。
- 表情状态：`idle`（呼吸+眨眼）、`thinking`（合成中，头顶波纹）、`happy`（成功，跳一下+星星）、`sad`（失败，垂头）。
- 交互：点击她 → 随机说一句鼓励/吐槽（toast 气泡），每天最多 3 次防烦。
- 可关：设置里"显示看板娘"开关，默认开，存 localStorage。

## 7. 布局（保持信息架构，换视觉）

- 侧栏 224px：白/磨砂渐变底 + 顶部品牌（展示字体），分组标题用极小字 + 斜切标签；激活项为渐变胶囊 + 右侧斜切高光。
- 顶栏 56px：磨砂白，页面标题（展示字体）+ 状态徽章（引擎/翻译/模型）+ 版本。
- 内容区：`max-width 1160` 居中，底部留 24px；卡片间距 16px。
- 合成页两栏不变：左栏（语言/台词/语气/CTA），右栏（模型卡含参考音频/音质微调/预设）。
- 结果卡：深色 HUD 面板（在浅色页面里形成"播放器"对比）。
- 响应式：1100 收窄、860 单栏、620 精简。

## 8. 启动器（launcher.cs / WinForms）

- 900×560 无边框窗口，圆角 Region，深海军蓝 `#0B1224` 底 + 极光渐变 + 网点。
- 左侧：LOGO（展示字体 TTF，已放 `launcher/assets/ZCOOLQingKeHuangYou.ttf`）+「VOICE DUBBING STUDIO」+ 版本。
- 右侧：原创少女 SVG/绘制剪影（GDI+ 几何），呼吸动画。
- 中部：三条状态（引擎 / 后端 / 模型）带呼吸灯：检查中=黄、就绪=绿、失败=红。
- 底部：主 CTA「开始使用」（斜切渐变、流光）、次按钮「打开数据目录」「关闭」；自定义标题栏可拖动，支持最小化。
- 启动动画：LOGO 斜切进场 + 扫描线，约 1.2s；状态齐了 CTA 才可点。
- 失败态：一句话人话 + 「重试」+ 「查看日志」。
- 兼容：DPI aware、记住窗口位置、启动后最小化可选。

## 9. 反模式（v2 新增）

- ❌ 亮底上用大面积纯白卡片铺满无层次（必须有背景渐变/纹理/阴影）
- ❌ 斜切/贴纸压在正文上影响可读
- ❌ 粒子/看板娘遮挡按钮或输入
- ❌ emoji 当图标（继续用 SVG sprite）
- ❌ 无 `reduced-motion` 兜底
- ❌ 展示字体用于日文假名（会回退成系统字体，混排难看）
- ❌ 动效导致布局跳动（transform 而不是改 margin/height）
